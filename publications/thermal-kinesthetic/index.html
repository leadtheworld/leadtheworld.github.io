A Wearable Encountered-Type ThermalKinesthetic Interface for Mars Exploration VR

Hoseok Jung, Jiyoon Lee, Sungmo Lee, Nahyun Lee, Seungwon Hu, Boyoung Kim, Okkeun Lee, Hyochang Kim, Hyunmin Kang

28th International Conference on Human-Computer Interaction (HCII 2026 Invited Papers)

Wearable force and thermal feedback for a Mars exploration experience.

Read manuscript ↗
Wearable hapticsVRPrototyping

Research overview

This work explores a wearable encountered-type interface that combines thermal and kinesthetic feedback for Mars exploration in VR. The interface brings physical sensation into a virtual exploration experience.

Wearable thermal and kinesthetic feedback

How can wearable haptic interfaces make a remote world tangible?

My role in this research program

Built thermal haptic devices within the SCIGC research program on physically tangible virtual experiences.

Connection to my broader work

Building physical feedback systems led me to ask how much stimulation is needed for a convincing virtual experience.
